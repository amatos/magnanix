# magnanix

My nix flake, using the denful pattern for NixOS, nix-darwin, and home-manager, using Determinate Nix.

Configuration is organised with [Den](https://github.com/denful/den), an aspect-oriented Nix framework: a
feature (an _aspect_) is written once and can configure `nixos`, `darwin` and `homeManager` together. Hosts
and users simply pick the aspects they want.

Every `.nix` file starts with a header that names its aspect, the platforms it configures and what it is for,
with notes on anything set differently from the defaults. When something is unclear, read that file's header first.

Documentation is best-effort, and believed to be correct -- however, I write documentation so that future me can understand what I did when something breaks at 3am. So, adjust salinity as required, and double check the actual docs if you're _borrowing_ my config. I have started using Claude to keep the documentation more up-to-date, so, fair warning that claude may hallucinate documenting something that I don't catch.

## Hosts

| Host                | Platform         | Kind       | User        | Notes                                                                                                           |
| ------------------- | ---------------- | ---------- | ----------- | --------------------------------------------------------------------------------------------------------------- |
| `magnus`            | `aarch64-darwin` | nix-darwin | `alberth`   | runs the darwintron and nixostron VMs; SSH (keys only)                                                          |
| `darwintron`        | `aarch64-darwin` | nix-darwin | `ephemeral` | [disposable Tart VM](documentation/testing-vms.md#testing-changes-on-darwintron)                                |
| `nixostron-aarch64` | `aarch64-linux`  | NixOS      | `ephemeral` | [disposable VM](documentation/testing-vms.md#testing-changes-on-nixostron) under Tart on magnus                 |
| `nixostron-x86_64`  | `x86_64-linux`   | NixOS      | `ephemeral` | [disposable VM](documentation/testing-vms.md#testing-changes-on-nixostron) under QEMU on muninn                 |
| `muninn`            | `x86_64-linux`   | NixOS      | `alberth`   | headless server: SSH (keys only), UEFI, Attic cache, SMTP relay, NTP server; runs the nixostron VM              |
| `fortuna`           | `x86_64-linux`   | NixOS      | `alberth`   | AMD desktop: Hyprland with Noctalia, LUKS + btrfs via disko, SSH (keys only); second drive reserved for Windows |
| `tenabrae`          | `aarch64-linux`  | NixOS      | `alberth`   | [Raspberry Pi Zero 2 W](documentation/tenabrae.md): Pi-hole with Quad9 over DoT, Wi-Fi, Tailscale, SSH (keys only) |

A host's name must match `scutil --get LocalHostName` (macOS) or `hostname` (NixOS), so that `darwin-rebuild` /
`nixos-rebuild` can find it. `base` sets the OS hostname from `den.hosts.<system>.<host>.hostName`, which defaults
to the host's name. The two `nixostron-*` hosts are the exception: one per architecture, both with
`hostName = "nixostron"` and both configured by `den.aspects.nixostron`. A macOS host also sets its display name in
its `darwin` block, as `magnus` does with `networking.computerName = "Magnus"`. OS options like `networking` only
work inside a `darwin` or `nixos` block; at the top level of a host file they are flake-parts options and fail.

## Layout

```
flake.nix          GENERATED by flake-file (`nix run .#write-flake`); do not edit
modules/den/       the framework and what every host shares (base, Determinate Nix, sops, Homebrew, Home Manager)
modules/flake/     the flake's outputs: configurations, nh wrappers, checks, dev shell, formatter
modules/packages/  opt-in aspects (features) that hosts, users or `base` include
modules/hosts/     one directory per host, plus templates/ for new hosts and virtual/ for the test VMs
modules/users/     one directory per user, plus a template for new users
pkgs/              the test VM scripts and locally packaged software
secrets/           sops-encrypted secrets
documentation/     everything that doesn't fit in this README
```

## Quick start

```sh
nix develop --command apply-configuration   # switch this machine to the flake
deploy-magnanix                             # pull main in ~/Developer/magnanix and switch (after CI passes)
```
